# Submission checklist — Meta Global AI Developer Hackathon 2026

Source: [official event page](https://cerebralvalley.ai/e/meta-ai-developer-hackathon). The event's complete binding rules and final portal instructions take precedence over this summary.

## Mandatory materials

- [ ] Read and accept the full official participation rules.
- [ ] Choose the correct entrant track and project theme.
- [ ] Complete the [Cerebral Valley submission](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit) as the human entrant.
- [ ] Provide a **public GitHub repository** that opens in a signed-out/incognito browser.
- [ ] Provide a **3-minute video** that demonstrates **new work completed during the event**.
- [ ] Ensure the repository contains runnable instructions, dependencies, synthetic test inputs, and an explicit limitation statement.
- [ ] Confirm that the solution legitimately uses the specified Meta AI products, and distinguish real model inference from mocked/deterministic outputs.
- [ ] Check there are **no secrets, customer information, private repository code, third-party proprietary assets, or unsafe repair instructions** in the public artifacts.
- [ ] Submit ahead of the deadline to allow for upload or portal failures.
